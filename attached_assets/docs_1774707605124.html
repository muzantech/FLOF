Bienvenue sur FLYHOST

FLYHOST est une plateforme d'hébergement nouvelle génération qui te permet de déployer, gérer et faire évoluer tes projets web et bots en quelques clics — sans configuration serveur complexe.

Déploiement instantané

Upload un ZIP ou connecte GitHub — ton projet est en ligne en moins de 2 minutes.

Auto-détection

FLYHOST détecte automatiquement si ton projet est en Python, Node.js, PHP ou Java.

Système de coins

Paye avec des coins FLYHOST. Gagne-en via le parrainage, les défis et les promotions.

Infrastructure fiable

Propulsé par Pterodactyl — isolation Docker, redémarrage auto, logs en temps réel.

Comment ça marche ?

FLYHOST fonctionne en 3 étapes simples :

1

Tu crées un compte et obtiens des coins

Inscris-toi gratuitement. Tu reçois des coins de bienvenue dès la première connexion. Les coins sont la monnaie virtuelle qui permet de louer des serveurs.

2

Tu crées un serveur depuis le wizard

Choisis un plan (Free, Starter, Pro, Premium), un type de projet et un nom. Le serveur est créé sur notre infrastructure en quelques secondes.

3

Tu déploies ton projet

Connecte ton dépôt GitHub ou upload un fichier ZIP directement depuis l'interface. FLYHOST configure automatiquement l'environnement et démarre ton application.

Système de coins 🪙

Les coins FLYHOST sont la monnaie virtuelle de la plateforme. Ils te permettent de louer des serveurs sans passer par un système de paiement classique à chaque fois.

Bonus inscription

Coins offerts à la création de ton compte.

Parrainage

Gagne des coins pour chaque ami invité qui crée un serveur.

Défis & challenges

Participe aux défis hebdomadaires pour gagner des récompenses.

Achat direct

Recharge ton solde via PayPal, carte bancaire ou crypto.

Codes promo

Utilise des codes promo pour obtenir des serveurs gratuits ou réductions.

Promotions flash

Des événements spéciaux offrent régulièrement des réductions importantes.

Guide pas à pas

Créer un serveur

Créer un serveur sur FLYHOST prend moins de 60 secondes. Voici le processus complet, étape par étape.

Avant de commencer

Assure-toi d'avoir suffisamment de coins dans ton solde. Le coût d'un serveur est affiché sur la page de création. Le plan Free est toujours gratuit et ne nécessite aucun coin.

Étapes de création

1

Ouvre le wizard de déploiement

Depuis le Dashboard, clique sur le bouton + Nouveau serveur ou accède à la page Déploiement. Le wizard s'ouvre automatiquement.

2

Choisis un serveur hôte

FLYHOST dispose de plusieurs nœuds d'hébergement géographiquement distribués. Sélectionne le serveur le plus proche de tes utilisateurs pour des performances optimales. Les serveurs affichent en temps réel leur charge CPU et mémoire disponible.

3

Sélectionne la méthode de déploiement

Trois méthodes sont disponibles :

GitHub

Connecte un dépôt GitHub. FLYHOST clone et déploie automatiquement à chaque push.

Fichier ZIP

Upload un fichier ZIP de ton projet. Idéal si tu n'utilises pas Git.

4

Sélectionne la technologie (optionnel)

FLYHOST détecte automatiquement si ton projet est en Node.js, Python, PHP, Java ou un site statique. Tu peux aussi le spécifier manuellement si besoin.

La détection automatique analyse les fichiers de ton projet (package.json, requirements.txt, pyproject.toml, etc.) pour choisir le bon environnement d'exécution.
5

Choisis ton plan

Sélectionne le plan adapté à ton projet. Les ressources (RAM, CPU, stockage) varient selon le plan choisi. Un aperçu du coût en coins est affiché en temps réel.

6

Nomme ton serveur et confirme

Donne un nom à ton serveur (ex: mon-api-backend). Vérifie le récapitulatif, applique un code promo si tu en as un, puis clique sur Lancer. Ton serveur est prêt en quelques secondes.

Après la création, tu seras redirigé vers la page de gestion de ton serveur où tu pourras voir les logs en temps réel, gérer les fichiers, configurer les variables d'environnement et contrôler le démarrage/arrêt.
Cas d'usage

À quoi servent les serveurs ?

Un serveur FLYHOST est un environnement d'exécution isolé, accessible 24h/24. Voici les usages les plus courants de notre communauté.

Bots Discord & Telegram

Héberge ton bot en permanence sans avoir besoin de garder ton PC allumé. Ton bot répond 24h/24, 7j/7 même si tu es déconnecté. Supporte Discord.js, discord.py, python-telegram-bot et tous les frameworks populaires.

Node.js Python Discord.js discord.py Telebot

Sites web & Applications web

Déploie ton site React, Vue, Next.js, ou un site statique HTML/CSS/JS. Parfait pour des portfolios, landing pages, projets d'école ou petits SaaS. Chaque serveur reçoit une URL publique accessible depuis internet.

React Next.js Vue HTML/CSS Static

APIs & Backends REST/GraphQL

Héberge ton API Express, FastAPI, Flask, Django ou Spring Boot. Expose tes endpoints REST ou GraphQL à tes applications mobiles, frontend ou services tiers. Idéal pour les projets full-stack où le backend doit tourner indépendamment du frontend.

Express.js FastAPI Flask Django Spring Boot

Automatisations & Scripts

Lance des scripts planifiés (cron jobs), des scrapers web, des automatisations de données ou des pipelines de traitement. Ton script peut tourner en continu ou être déclenché périodiquement selon une logique que tu définis dans ton code.

Cron jobs Web scraping Automation Data pipeline

Jeux & Serveurs de jeu

Héberge un serveur de jeu multijoueur, un moteur de jeu en ligne ou les fonctions temps-réel de ton jeu (WebSockets, rooms, matchmaking). Compatible avec Socket.io et les architectures temps-réel modernes.

WebSocket Socket.io Multiplayer Real-time

Projets scolaires & Portfolio

Présente ton projet de fin d'études, ton stage ou ton portfolio en ligne. FLYHOST permet de partager une URL live sans frais élevés. Parfait pour montrer ton travail à des recruteurs ou correcteurs avec un vrai lien fonctionnel.

Portfolio Projet d'école Stage Démo

Technologies supportées

FLYHOST supporte nativement les principales technologies web et backend. La détection est automatique — il suffit d'uploader ton projet.

Node.js

Express, Fastify, NestJS, Discord.js, Socket.io. Détecté via package.json.

Python

Flask, FastAPI, Django, discord.py. Détecté via requirements.txt ou pyproject.toml.

PHP

Laravel, Symfony, WordPress, PHP natif. Détecté via composer.json.

Java

Spring Boot, Maven, Gradle. Détecté via pom.xml ou build.gradle.

Site statique

HTML, CSS, JS pur. Servi via Nginx/serve. Parfait pour landing pages et portfolios.

Projets mixtes

Backend Python + frontend React : FLYHOST détecte et priorise le backend automatiquement.

Si FLYHOST détecte la mauvaise technologie, tu peux forcer manuellement l'environnement depuis le wizard (étape "Technologie") ou en ajoutant un fichier .flyhost.json à la racine de ton projet avec {"env_type": "python"}.

Déploiement

Déployer depuis GitHub

Le déploiement GitHub est la méthode recommandée pour les projets actifs. Il permet de mettre à jour ton application directement depuis ton dépôt.

1

Connecte ton dépôt GitHub

Dans le wizard, choisis la méthode GitHub et colle l'URL de ton dépôt. Pour les dépôts privés, ajoute un token d'accès GitHub (Personal Access Token avec permission repo).

2

Choisis la branche

Spécifie la branche à déployer (main, master, production…). FLYHOST clonera toujours la dernière version de cette branche.

3

Ajoute tes variables d'environnement

Définis tes API_KEY, DATABASE_URL, SECRET etc. directement dans l'interface. Elles seront injectées dans l'environnement de ton application sans être exposées dans ton code.

4

Lance le déploiement

Clique sur Déployer. FLYHOST clone le repo, détecte la technologie, installe les dépendances et démarre l'application. Tu vois les logs en temps réel.

Déployer via fichier ZIP

Si tu n'utilises pas Git ou que tu veux uploader un build compilé, le déploiement ZIP est parfait.

1

Prépare ton ZIP

Crée un fichier ZIP avec tous les fichiers de ton projet à la racine (pas dans un sous-dossier). Inclus package.json, requirements.txt ou l'équivalent selon ta techno — FLYHOST s'occupe de l'installation.

# Structure recommandée dans le ZIP mon-projet.zip ├── index.js # (ou app.py, index.php...) ├── package.json ├── .env.example # Variables d'env exemples └── src/
2

Upload et déploie

Dans le wizard, sélectionne Fichier ZIP, glisse ton fichier dans la zone d'upload. Le déploiement commence automatiquement. Taille maximale : 100 MB.

Détection automatique d'environnement

FLYHOST analyse les fichiers de ton projet pour configurer automatiquement le bon runtime Docker, installer les dépendances et définir la commande de démarrage.

Fichier détectéTechnologieCommande auto
package.jsonNode.jsnpm install && npm start
requirements.txtPythonpip install -r requirements.txt && python app.py
pyproject.tomlPython (Poetry)pip install . && python main.py
composer.jsonPHPcomposer install && php -S 0.0.0.0:$PORT
pom.xmlJava (Maven)mvn package && java -jar target/*.jar
index.html uniquementSite statiquenpx serve . -p $PORT
Si ton projet a une structure non-standard (ex: entry point dans un sous-dossier), crée un fichier .flyhost.json à la racine pour spécifier manuellement : {"env_type": "python", "start": "python backend/server.py"}
FAQ

Questions fréquentes

Puis-je héberger plusieurs serveurs simultanément ?
Oui, il n'y a pas de limite au nombre de serveurs. Chaque serveur consomme des coins selon son plan. Tu peux mixer des serveurs Free, Starter et Premium sur le même compte.
Que se passe-t-il si mon solde de coins est à zéro ?
Les serveurs payants peuvent être suspendus si le solde est insuffisant pour le renouvellement. Les serveurs Free ne sont pas affectés. Tu recevras une notification avant toute suspension. Recharge ton solde pour réactiver tes serveurs.
Mon bot/application peut-il accéder à internet ?
Oui, les serveurs FLYHOST ont un accès complet à internet en sortie. Ton application peut appeler des APIs externes, envoyer des emails, se connecter à des bases de données cloud, etc.
Comment ajouter un nom de domaine personnalisé ?
Chaque serveur reçoit une URL FLYHOST par défaut. Pour un domaine personnalisé, configure un reverse proxy (Cloudflare, Nginx) qui pointe vers l'IP et le port de ton serveur, disponibles dans la page de gestion.
Puis-je utiliser une base de données ?
Tu peux utiliser des bases de données cloud externes (MongoDB Atlas, PlanetScale, Supabase, etc.) via des variables d'environnement. SQLite et fichiers JSON locaux fonctionnent également mais sont réinitialisés lors d'une réinstallation du serveur.
Comment voir les logs de mon application ?
Accède à la page de ton serveur depuis le Dashboard. L'onglet Console affiche les logs en temps réel via WebSocket. Tu peux aussi y exécuter des commandes directement dans le conteneur.
Comment fonctionne le redémarrage automatique ?
Si ton application crash (exit code non-zéro), Pterodactyl la redémarre automatiquement selon la politique configurée. Tu peux voir le nombre de redémarrages dans les statistiques de ton serveur.
Mes données sont-elles sauvegardées ?
FLYHOST propose un système de snapshots/backups accessible depuis la page de gestion du serveur. Les plans Pro et Premium bénéficient de sauvegardes automatiques quotidiennes.
Comment contacter le support ?
Ouvre un ticket depuis la page Support. Le temps de réponse moyen est de moins de 2 heures. Pour les urgences, rejoins notre serveur Discord communautaire.
